# GPT Doc Reader

A tool to read and manage documents generated by ChatGPT.

## Features

- 📄 Read and parse ChatGPT-generated documents
- 🔄 Convert documents to various formats (Markdown, PDF, etc.)
- 📝 Manage and organize document collections
- 🔍 Search and filter documents
- 💾 Store documents locally or in cloud storage
- 🔗 Integration with web-to-markdown for web content conversion

## Installation

### Prerequisites

- Python 3.8+
- pip

### Setup

```bash
# Clone the repository
git clone https://github.com/xujingrong021218-ship-it/gpt-doc-reader.git
cd gpt-doc-reader

# Install dependencies
pip install -r requirements.txt
```

## Usage

```python
from gpt_doc_reader import DocumentReader

# Initialize the reader
reader = DocumentReader()

# Load a document
doc = reader.load_document('path/to/document.txt')

# Convert to markdown
markdown = reader.to_markdown(doc)

# Save the result
reader.save(markdown, 'output/document.md')
```

## Configuration

Create a `.env` file in the root directory:

```env
# Document storage settings
STORAGE_PATH=./documents
OUTPUT_FORMAT=markdown

# Optional: API settings for ChatGPT integration
OPENAI_API_KEY=your_api_key_here
```
